# 中文运营工作台

首次克隆后，Windows 在项目根目录执行 `./Setup.ps1`，macOS/Linux 执行 `bash ./setup.sh`；填写根目录 `.env` 后，分别执行 `./Start.ps1` 或 `bash ./start.sh`。打开 [工作台](http://127.0.0.1:4330)。Paperclip 默认关闭，启用方式见根目录 README。

开发者可继续阅读[系统架构](../docs/architecture.md)、[开发与测试](../docs/development.md)和[运行与数据安全](../docs/operations.md)。

## 使用顺序

1. **产品资料**：填写名称、AppID、入口路径，上传 DOCX/TXT/MD。点击整理定位，检查受众、可用功能与禁止说法后确认版本。已有产品与三份资料已导入。
2. **发布账号**：添加公众号、头条或小红书账号，在 ego-lite 由本人登录，再检查状态。公众号可读取后台可见历史文章，供后续选题参考。
3. **新建内容任务**：选择产品、平台及调用上限，主题可留空。依次选题、检索近一周公开文章、分平台写稿、审查事实、由独立漫画绘图 agent 调用火山引擎分别生成封面与正文插图，按文章场景选用产品资料中的二维码和页面截图。Paperclip 分配给运营负责人的 todo 任务也会导入。
4. **审核并上传草稿**：查看正文与配图，可手动改稿或提交修改意见。选择账号，确认后只上传正文、封面和插图到草稿箱。公众号上传不额外调用模型。程序不执行发表，旧“批准发布”接口也只会上传草稿。
   审核意见支持分项显示。配图包含火山引擎生成的漫画封面和无文字正文漫画插图。封面失败会保留正文，不使用模板代替 AI 图片。同一版本可多次确认上传，每次新建一份草稿，保留旧稿；上传中禁止并发重复提交，历史上传记录可在内容页面查看。
5. **手工发表和复盘**：上传成功后，到公众号管理后台自行发表。回到工作台登记真实文章链接，才记录为已发表，并安排统计。草稿上传成功不会冒充发表成功或立即启动发布后收数。
6. **周期运行**：在运行设置启用下一期计划，选择产品、平台、间隔天数和调用上限。登记真实发表链接后，自动收数可在24/48/72小时各尝试一次，每次最多2次模型调用，失败停止并保留原因。程序需要保持运行；关闭后不会后台执行，重启不会补建大量逾期任务。

## 配置和费用

写作和绘图配置统一从项目根目录 `.env` 读取，包括 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`、`DEEPSEEK_BASE_URL`、`ARK_API_KEY`、`ARK_IMAGE_MODEL` 和 `DEFAULT_MAX_CALLS`。“运行设置”页面只显示非敏感摘要并提供文字模型、图片模型的独立连接测试，不保存或回显 API Key。修改 `.env` 后需要重启工作台。连接检查只读取模型列表，不生成文章或图片，也不占任务调用预算。每个平台分别生成一张漫画封面和一张无文字正文漫画，按火山接口单独计费，不占 DeepSeek 写作次数；成功图片按内容缓存，续跑时复用。相同稿件已成功的封面直接复用；超时等结果未知时停止重试，避免重复扣费。

OpenClaw 负责隔离角色的模型执行，Paperclip 管理任务，本地服务控制预算、审批和浏览器动作。服务只绑定本机 127.0.0.1。关闭启动窗口即停止，再启动保留记录。

传给模型的历史文章、摘要和研究来源有数量与长度限制，不传整份排版 HTML、浏览器回执或完整后台页面。模型执行器为当前输出上限预留回复空间，避免历史积累后被本地长度检查拦截。生成中断可复用已完成的研究和写稿步骤，部分平台完成后仍可接续剩余平台；内容模型网络中断、429 和服务端异常会自动重试，最多共 3 次尝试，间隔 2 秒、4 秒，所有付费尝试仍计入任务调用上限。重试可能产生额外费用。认证等明确不可恢复错误直接停止。历史模型中断任务在重启后自动接续一次，保留已完成步骤。上传、发表及图片生成的结果保护单独保留。任务详情可展开调用日志，查看 callId（链路标识）、角色、阶段、HTTP 状态、上游请求标识、耗时、错误代码和用量；不记录密钥或请求正文。旧日志未保存的信息不能补回。

## 已验证与待验收

- 已验证文档导入、国内中文文章检索、真实 DeepSeek 出稿、PNG 配图、版本审核保护、中文页面与持久化恢复。
- 已验证公众号登录状态检查和后台可见历史文章读取流程；实际可读取范围取决于当前登录账号。
- 周期选题与数据回收调度已接入并通过虚拟时钟测试，真实长期运行需在文章获批发布后继续观察。
- 当前自动草稿上传仅支持微信公众号；头条、小红书保留内容生成和导出，自动上传未验证。账号扫码或权限提示仍由本人操作。
- 微信草稿已删除时，不向失效页面反复保存。程序会识别对应旧稿后创建新草稿；中途失败会保留已完成步骤，且必须取得本次保存成功提示才能标记上传成功。
- 自动发表已关闭，浏览器模型只保留只读数据采集能力。历史发表结果不明的记录保留，不能借切换模式自动重发。
- 公开检索只提供有日期的文章线索，没有真实传播量不会声称爆款。平台互动不等于小程序新增使用，没有渠道来源统计不声称精确归因。

## 数据和检查

`app/data/operator.sqlite` 保存产品、任务、稿件、审批、回执与效果；图片和调用记录也在 `app/data/`，整个目录被 Git 忽略。迁移前备份。平台密码和 Cookie 不保存到业务数据库，登录会话由 ego-lite 保存。

项目根目录运行：

```bash
node --test app/tests/*.test.mjs
```

产品资料的「二维码与页面截图」支持上传 PNG/JPEG 原图、用途说明和适用平台（默认头条）。写作模型仅按相关场景选择已上传的图片 ID，不生成或猜测二维码、界面。正文漫画放在文章段落之间，所选产品原图随正文展示；预览、离线 HTML 导出和公众号草稿上传均携带这些图片。停用素材只影响后续选用，已有稿件仍保留。
